# 🎟️ TicketHub - Online Movie Ticket Booking System

## 📌 Overview
**TicketHub** is a **full-stack web application** designed to provide a seamless and secure **movie ticket booking experience**.
## 🚀 Features
- 🔐 **User Authentication & Role Management** (Customer, Theater Owner, Admin)
- 🎬 **Movie Discovery & Search** with real-time filtering
- 🪑 **Dynamic Seat Selection & Booking System**
- 💳 **Secure Payment Gateway Integration** (Razorpay, PayPal, UPI, Credit/Debit Cards)
- 📩 **Automated Email & SMS Notifications** for booking confirmations & reminders
- 📊 **Analytics Dashboard** for movie performance tracking
- 🔒 **JWT Authentication & Role-Based Access Control (RBAC)**
- ☁️ **AWS Deployment** for high availability and scalability

## 🛠️ Tech Stack
### **Frontend: 🎨**
- ReactJS (UI Components, Hooks, State Management)
- Bootstrap & Material UI for responsive design
- Axios for API communication

### **Backend: 🧑🏻‍💻**
- Spring Boot (REST APIs, Business Logic, Security)
- MS.NET for scalable backend services
- MySQL (Relational Database, Stored Procedures, Optimized Queries)

### **Security: 🔐**
-  **JWT Token Authentication** for secure access
-  **Password Encryption (BCrypt)**
-  **Role-Based Authorization** (Admin, Customer, Theater Owner)
-  **Secure Payment Processing** via Razorpay API
